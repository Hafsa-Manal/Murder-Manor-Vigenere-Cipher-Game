◆ WHAT IS THE VIGENÈRE CIPHER?
Each letter in the message is shifted by the value of the matching key letter. The key LOL repeats across the whole message — L then O then L then back to L, and so on.

to decrypt: subtract the key value instead.
if the result is negative, add 26 to wrap around.
spaces & punctuation are left unchanged.
