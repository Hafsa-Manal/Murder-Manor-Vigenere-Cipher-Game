# 🕵️ Murder at the Manor

An interactive **Vigenère Cipher learning game** that combines cryptography with a detective mystery. Players learn encryption and decryption through a tutorial and solve three encrypted clues to uncover the case.

## Features

* 🕵️ Detective story
* 🔐 Vigenère Cipher tutorial
* 🧩 3 encrypted puzzles
* ✅ Answer validation
* 📈 Progress tracking
* 🎨 Retro pixel-themed UI

## Tech Stack

* **HTML** – Structure
* **CSS** – Styling
* **JavaScript** – Game logic and validation

## How to Run

Open `index.html` in any web browser.

**No additional installation required.**
